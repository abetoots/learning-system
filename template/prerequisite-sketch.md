# What has to be true first

Two jobs. The first is a hard blocker — do it before you study anything.

## 1. The answer-key contract

You cannot learn alone if nothing can tell you you're wrong. Practice you never check locks mistakes in.

| | |
|---|---|
| **What tells me I'm wrong** | <from INTAKE Q4: the course's tests · the textbook key · <mentor> · the world · `drill-bank.md` pointers> |
| **How often it looks** | <cadence — a fixed day> |
| **I bring** | the attempt first. Never a blank page and a question |
| **I also bring** | what I tried and what I think is wrong |
| **I write down** | why I was wrong — in `error-log.md`, not in my head |
| **Who reads the error log, AI column included** | <mentor, every session · or: me, weekly, and the monthly AI-off test is the check> |

**AI is not the answer key.** The risk isn't that it's wrong; it's that you can't yet tell a good answer from a confident wrong one, and that judgment is what you're here to build. Attempt first; ask it to critique the attempt; never ask it for the answer.

## 3. This week's targets

Whoever the intake named sets the order — a course if you're following one; the target performance if you're reactivating; the feedback source if the field is new. If someone is mentoring you, their job is not ordering; it's finding what the source assumes but never teaches. A target with nothing to learn from is not a target yet.

Carry-over is normal. You are not meant to clear the board every week.
