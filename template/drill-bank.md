# Drill bank

**Only if INTAKE Q4 = none, and the track is A or B** — no course with graded labs, no textbook key, no test suite, no mentor. Then the answer key has to be built, and this is it. Delete this file otherwise. **Not for Track C:** in a new field you can't yet tell a good source from a wrong one, so a bank you build is a key you can't check — find something that can grade you first.

**The pointers are the reference answer.** Write each question's answer-key pointers *from the source, before the first cold attempt* — a page, a section, a file and line, a named artifact. Never from memory; that is the thing being tested.

**Cold mark** — first attempt, everything closed, answered out loud or on a blank page: `defends` (could argue it against pushback) · `recognizes` (knew it when you saw the pointer) · `blank`. Date it. `blank` routes to `never-learned` in the error log — build a completion problem from the source and the item is done only when a cold pass opens a *later* session. `recognizes` routes to `forgot`. Record the later pass next to the mark: `blank 9/2 → defends 9/4`.

Answer the bank cold, on the schedule in `README.md ## Plan`. Rate confidence before checking. Misses go to `error-log.md` with `Source = DB #n`.
