# Mentor's operating doc

**Only if INTAKE Q3 = mentor + learner.** Audience: the mentor. Nothing here goes in the learner's files — if it creeps back, pull it out again.

## Who owns what

| Thing | Owner | Cadence |
|---|---|---|
| The sequence | whoever the intake named: the course (B), the target performance (A), the feedback source (C). If the intake named *you* as the feedback source, ordering is yours — otherwise it isn't | fixed |
| `competency-list.md` | **they write; you read, never edit** | daily |
| The week's 2–3 targets | agreed together | Saturday |
| `prerequisite-sketch.md §3` | you supply the judgment, they hold the pen | Saturday |
| `error-log.md` | they write; **you read every session, AI column included** | — |
| Gap detection — what the source assumes but never teaches | **you. The one thing only you can do** | Saturday |
| Provenance and carry-over bookkeeping | you, in this file | Saturday |

## Saturday, one hour

1. **Source first (2 min).** They read out the next 2–3 items from whatever sets the order — course sections, target performances, or your own list if you're the feedback source. That's the order.
2. **Convert to "I can…" lines (10 min).** Together. Then interrogate: what should they be able to *do* after this? Does it quietly assume something nobody taught? **"Did the video cover that, or just use it?"** Small enough for a week?
3. **Mark provenance** — here, not in their file: `C` from the course · `G` a gap you found · `R` redo, proof failed or recurring in the log.
4. **`G` lines need a teacher.** Before it enters the week: you explain it now, or you name one specific thing to read or watch, or you point at a later section. None available → park it.
5. **Keep / Split / Replace.** Survivors carry forward with a new date. All Keep is a good week.
6. **Read the error log (2 min),** AI columns included. Rows that say "used AI, nothing went wrong" are the log working; their absence is the worry.
7. **Classify stalls, don't blame them:** never worked on → smaller; missing prerequisite → add it ahead; too big → split.
8. **Name one thing to stop doing.**

## Week 1 is not a normal week

Day 0, one sitting, before Monday, separate from the first study session: sign the contract in the sketch, check the source is live, draft 3–5 first lines (they type every word), teach the first `G` line yourself, name Monday's first item. Monday opens with a *prediction*, not recall — there's nothing behind it yet. The first log read is for compliance (are rows being written?), not patterns.

## What to watch

| Signal | Means |
|---|---|
| List fills with mechanical lines, empties of "I can explain why" | optimising for the typeable; you'll see it before they do |
| `answer` outnumbers `hint` in the AI column | cut to critique-only until it turns |
| Lots covered, little rebuilt from blank | watching, not doing |
| Same misconception three weeks running | one curriculum item, top of the week |
| Saturday runs long | you're transferring answers instead of asking questions |

Weeks 3–4 will feel worse. Tell them in advance; it lands differently as a prediction than as a diagnosis.

Runtime note: on Notion Free, join their workspace as a **guest**. A second owner triggers the 1,000-block cap.
